## Context

現在設定できるオブジェクトと各パラメータの表現範囲だけを使い、既存テンプレートを含めて合計10件の実用可能なサムネイルテンプレートを整備する。新しい表現要素を前提にせず、現行機能で破綻なく利用できるテンプレートに限定する。

## Acceptance Criteria

- [x] 既存テンプレートを含めて合計10件のテンプレートが利用可能になっている
- [x] 各テンプレートが現在設定可能なオブジェクトとパラメータのみで構成されている
- [x] 各テンプレートを読み込んだときにレイアウト崩れや未対応パラメータが発生しない
- [x] テンプレートごとに用途や見た目の差分が判別できる

## Notes

- Added six supported default templates: Breaking News, Versus Comparison, Gaming Highlight, Podcast Guest, Event Countdown, and Minimal Launch.
- Validation: `npm test`, `npm run build`, and Playwright headless Chromium runtime gate passed on 2026-06-07.
