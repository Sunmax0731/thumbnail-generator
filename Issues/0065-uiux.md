## Context

優先度高めのUIUX改善として、初心者や急ぎの配信者が短時間でサムネイルを作成できる導線を追加する。制作フロー、テンプレート選択、出力設定、カラー設定、モバイル作業導線を整理し、既存機能の強さを保ちながら初期体験と操作効率を改善する。

## Acceptance Criteria

- [x] 「テンプレ選択 -> 画像差し替え -> タイトル入力 -> 色調整 -> 書き出し」の短いステップモードで主要制作フローを進められる。
- [x] テンプレート一覧に小さなサムネイルプレビュー、用途カテゴリ、YouTube/Shorts/配信/切り抜きフィルタが表示される。
- [x] トップツールバーは通常表示で「プリセット」「形式」「書き出し」を優先し、詳細サイズ・品質・個別形式設定は折りたたみなしで操作できる。
- [x] カラー機能は「ブランドカラー」「おすすめ配色」「最近使った色」を優先表示し、詳細カラーホイールなどのAdvanced扱いも利用できる。
- [x] モバイル初期表示ではキャンバスが主作業領域として先に見え、編集パネルが下に続く制作優先レイアウトになる。
